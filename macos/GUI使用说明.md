# 原生 Mac 主题管理器

## 打开

从顶部菜单栏退出旧版 Dream Skin，再打开 `release/Codex Dream Skin GUI.app`。关闭窗口后仍可从 Dock 或菜单栏「打开主题管理器」重新打开。
新版本沿用现有主题库；仅选择预览不会切换正在使用的皮肤。

## 与 Windows 对应的功能

| Windows 功能 | Mac 原生窗口 |
| --- | --- |
| 主题库搜索、分类 | 名称/标签搜索，分类、静态/动态过滤 |
| 全部 / 内置 / 我的 | 来源筛选 |
| 目录顺序 / 名称排序 | 使用 Windows 预设目录顺序；另提供最近修改 |
| 添加图片 | 多选图片/视频，最多 50 项，重复跳过并显示逐项结果 |
| 导入/导出主题 | 读取/写入 formatVersion 1 的 `.cdskin`；也可导入 Mac ZIP |
| 删除主题 | 当前及默认主题禁止删除；内置移入废纸篓，自定义确认后永久删除 |
| 下载素材 | 保留原始媒体文件格式 |
| 应用 / 暂停 / 恢复 / 重置 | 复用 Mac 换肤引擎；恢复默认主题与恢复原貌分别提供 |
| 恢复原貌 | 确认后停止换肤、恢复配置并重启 Codex；保留主题库 |
| 检查上游更新 | 独立 GUI 发布通道：签名校验、下载、替换与重启 |
| 导入图片参数编辑 | 单选素材后预览、编辑，支持保存主题、保存并应用 |
| 主题参数编辑 | 保存原主题修改、另存为新主题、保存并应用、恢复已存参数 |
| 取景参数 | 独立焦点、位置、缩放、锁定/自由移动、取景开关及复位 |
| 外观参数 | 浅/深色、文字安全区、任务页模式、气泡/面板不透明度、强调色/清除 |
| 分类和标签 | 名称、分类、最多 8 个标签，每个最多 20 字符 |

编辑当前使用的主题并保存时，会重新应用；需要重启 Codex 时仍使用原有确认流程。
保存参数与动态画面的实际效果以应用后的 Codex 为准；设置页展示取景/透明度示意。

GUI 0.1.3 起，应用已保存的 MP4 主题会先建立 Codex 连接，再验证真实视频解码能力。Codex 未启动时会自动打开；已启动但尚未连接换肤运行时时会询问是否重启。取消重启或视频校验失败时，所选主题不会写入当前主题。首次启动会等待主窗口就绪，避免把窗口尚未加载误判成无法播放。

`.cdskin` 的背景、参数、Safe CSS、LICENSE 会转换并保留。按照 Windows formatVersion 1 限制校验包结构、CRC、路径及大小；导入视频仍需通过现有 Mac 引擎解码校验。GUI 的新导入与 Windows 一致，支持 PNG/APNG/JPEG/WebP/GIF/MP4；HEIC/TIFF 请先转换 PNG。旧命令行入口仍可将它们无损转成 PNG 并保留源文件。
批量结果、重复与失败原因可在底部「操作记录」查看，记录只在当前运行期间保留。

## 平台差异

Mac 使用原生窗口、系统播放器及废纸篓，不复用 Windows WPF/安装器。
更新仅使用本构建配置的发布者仓库和 `gui-v*` 版本，不安装普通上游菜单栏发行包。
此处的主题库、导入导出、编辑和控制操作按 Windows 对齐；Windows 的打赏页面和 EXE 自动安装器不移植。

## 构建

安装同版本的官方 Dream Skin Mac 包后运行：

```bash
bash macos/scripts/build-local-gui.sh
```

脚本使用已安装的同版本 App 提供 Node 和引擎资源，在当前架构编译 GUI 并打包更新的管理脚本。不覆盖已安装应用，不运行测试，不启动 GUI；已有输出时须指定新的输出路径。
系统 CLT 若留下重复 SwiftBridging 定义，脚本只在本次编译映射中隐藏旧定义，不修改系统文件。

验证边界：本地自签名构建；已做编译、脚本语法和签名检查，未进行 GUI 操作或实际导入、删除、换肤验收。

## 本地修订：导入与预览一致性

- 安装/修复只补充缺失的预设；不清理旧预设、不覆盖已保存参数。通过新版删除的内置主题会记录删除标记，修复时不重新添加。
- 导入在独立临时目录完成校验，再发布到主题库；选择“应用”后才通过切换器更新当前主题。
- 新导入保留媒体原始字节、格式、透明通道和分辨率，不压缩为 JPEG。
- 批量图片、单张保存与 `.cdskin` 共用同一内容指纹，按媒体、显示参数和 CSS 判断重复，不因改名、改标签或 JSON 字段顺序重复导入。
- 缩略图、控制台和设置预览使用 Windows 同款裁剪/位置/缩放计算。视频取景看封面预览；“播放原始视频”单独打开原生播放器。
- 上游更新不等同于本地 GUI 更新；所有手动/通知入口先提示需要合并源码重建，避免直接覆盖丢失功能。未建立此定制版的自动更新发布服务。

这些修复不会追溯修改已导入的文件；以前压缩过的素材需从原图重新导入，之前被删除或覆盖的主题不会自动恢复。

## 独立自动更新（GUI 0.1.0 起）

前述“仅查看上游发行说明”已由独立 GUI 更新通道替代。配置发布者的构建会自动检查 `gui-v*` 发布版本，提示后下载、验签、安装并重启管理器；保留旧 App，主题资料不迁移、不删除。无配置的开发构建会明确显示“未配置更新发布者”。具体发布与回滚方式见 `UPDATER.md`。
