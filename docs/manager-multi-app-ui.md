# Codex / Claude Desktop 管理器界面

在现有 `ui/manager/` 中实现，沿用一套管理器和主题库。2026-11-09 用户已通过左侧图标竖栏版 UI 审阅，保持布局并开始接入 Claude Desktop 功能。

## 布局

```text
[Codex图标]   控制台 / 社区 / 导入 / 设置                    状态 / 更新
[Claude图标]  主题库                                当前目标控制面板
              搜索 / 分类 / 来源 / 排序               应用结构预览
              添加图片 / 导入主题包 / 导出            选中主题 / 当前皮肤
              主题缩略图列表                         应用到 Codex / Claude Desktop
                                                    参数 / 暂停 / 恢复
```

应用切换放在左侧竖排菜单，只显示原图标；悬停提示和可访问名称保留应用名。右侧导航与页面共用宽度和左边界，“控制台”按钮与主题库对齐。保留竖栏空间供以后增加目标，不增加假按钮或新管理机制。必要状态与错误提示继续显示。目标切换只切换管理上下文，不自动应用。主题库保留同一份选中素材，方便比较两种预览。操作执行中或存在未保存草稿时不能切换目标，异步导入和社区流程也保留最初目标。

## 复用与区分

| 区域 | 共用 | 按应用区分 |
| --- | --- | --- |
| 主题库 | 图片、动图、视频、分类、搜索、主题包、社区、导入导出 | 活动引用分别记录，共同参与删除保护 |
| 控制面板 | 选主题 → 预览 → 应用的布局 | 应用按钮名称、当前皮肤、连接状态、暂停与恢复 |
| 参数页 | 编辑器组件、媒体资源、缩放取景与透明度控件 | Claude 参数独立持久化，不修改 Codex 的主题参数 |
| 预览 | 同一媒体读取及裁剪逻辑 | Codex / Claude Desktop 的页面示意壳 |
| 启动动画 | 默认动画、视频播放、跳过及设置组件 | 两端独立设置，Claude 随新建/重载 Code 文档播放 |
| 专属能力 | 按实际页面能力启用 | Codex 专用 CSS、任务页模式、文字安全区不套用 Claude |
| 管理器 | 语言、软件更新与系统入口 | 后续连接引导按应用提供 |

## 本轮可以审阅的交互

1. 在左侧通过图标切换 Codex / Claude Desktop，主题库保持不变，状态和控制面板随目标切换。
2. 选择图片、动图或视频查看 Claude Desktop 页面示意，点击“编辑参数”进入参数页；视频可调整播放速度。
3. 调整遮罩、面板透明度及取景，预览跟随变化；参数保存至 Claude 独立目录，不回写共享主题。
4. Windows 上手动通过 Claude 的 `Developer → Enable Main Process Debugger` 开启原生入口，刷新状态后应用、暂停、继续、重置或恢复；管理器不会自动打开该入口。恢复确认框中的取消不发送变更。
5. 在 Claude 上下文进入社区或导入页，共用素材管理，可保存并应用至 Claude；异步操作固定发起时目标。
6. 启用/关闭 Claude 启动动画，使用默认动画或选中的视频，支持恢复默认；普通换肤不重播。设置已保存但连接更新失败时分别提示。

## 实现边界与后续

- Codex 沿用既有功能及参数储存；新增窄 `claude.*` 契约接入独立核心和 Windows 适配，不扩展 Codex 页面验证条件。
- Claude 参数从选中主题的默认参数起步，另行保存调整。状态和操作回执保存在 `claude-desktop/`；应用图片保留独立快照，暂停后继续不依赖共享库原文件。
- 当前支持 Windows 上已验证的 Code 页面，接受 JPEG/PNG/WebP/GIF/APNG/MP4。主题中的 Codex 专用 CSS 不注入 Claude。气泡透明度未接入，Claude 参数页隐藏该项。
- 预览页面壳为示意，不承诺与真实 Claude 完全一致。Claude 主进程内控制器维护新建/重载页面，管理器关闭不撤销已应用皮肤；Claude 整个进程退出后需重新连接应用或配置，不承诺跨进程自动恢复。
- 应用切换使用用户指定的 Codex 白色圆角图标与 Claude 橘色原生图标。来源见 `ui/manager/src/assets/SOURCES.md`，随 UI 内嵌，运行时不读取本机安装目录。
- 2026-11-08 最新 Windows x64 审阅包：`build/CodexDreamSkinManager-icon-rail-ui-20261108/CodexDreamSkinManager.exe`，只进一步调整左侧纯图标菜单和导航对齐。core、UI、原生宿主编译及资源组装完成；独立静态审查无实质问题，包内容及原图标内嵌核对通过。未运行完整测试、额外类型检查或视觉验证，旧安装包不会自动包含本次 UI。

上述审阅包是历史 UI 包，不包含后续核心源码。功能开发的隔离 Proof 与真实 Claude 应用、恢复验收分别记录；本次未重新打包或代操作真实应用。
